# Atenir · sito vetrina

Sito statico (HTML, CSS, JS, nessuna dipendenza) per Atenir: berrette, sciarpotti e borse all'uncinetto.
Online su GitHub Pages dal ramo `gh-pages`.

## Contatti
In cima a `script.js` c'è `CONTATTI`: Instagram, TikTok, WhatsApp, email. Quelli lasciati vuoti non compaiono.

## Foto vere dei prodotti
Le foto sono in `assets/foto/` in formato WebP (leggero), larghe al massimo 900 px. Per cambiarne una sostituisci il file con lo stesso nome, per esempio `berretta-1.webp`
(meglio verticale 4:5).

## Struttura
- `index.html` – contenuti
- `styles.css` – stile
- `script.js` – contatti, collezione, gomitolo che segue lo scorrimento, cucitura delle foto, animazioni

Il colore del filo che cuce ogni foto è scritto nell'attributo `data-filato` della foto in `index.html`.
